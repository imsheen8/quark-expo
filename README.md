# QUARK AI — نسخة Expo (React Native)

إعادة بناء كاملة من الصفر لتطبيق QUARK AI باستخدام **Expo SDK 54 + expo-router + TypeScript**، بدل نسخة الويب/Capacitor القديمة. الواجهة عربية RTL بالكامل، والتطبيق يتصل مباشرة بالمزوّد من الهاتف (لا حاجة لبوابة بايثون ولا لإعداد CORS).

## التشغيل

```bash
npm install
npx expo install --fix      # يوائم أرقام إصدارات الحزم مع SDK المثبّت عندك
npx expo start              # امسح الرمز بتطبيق Expo Go (أندرويد/آيفون)
npm test                    # اختبارات المنطق (30 اختبارًا)
```

> بُني المشروع في بيئة بلا وصول لمستودع npm، فلم يُشغَّل على جهاز/محاكي ولم يُجرَ فحص `tsc` كامل. اختُبر المنطق الصرف بالاختبارات وفُحصت صياغة كل الملفات. أول تشغيل قد يكشف تفاصيل صغيرة في الأنواع أو أرقام الإصدارات — `npm run typecheck` يدلّك عليها.

### بناء APK / تثبيت

```bash
npx eas build -p android --profile preview     # APK عبر EAS
# أو محليًا:
npx expo prebuild && cd android && ./gradlew assembleRelease
```

## ما لم يُنقل (يحتاج وحدات أصلية أو خادمًا) 

- **النماذج على الجهاز (llama.cpp / wllama)** والتنزيل في الخلفية — تحتاج وحدة أصلية مخصصة (مثل `llama.rn`) وبناء Development Build.
- **ودجتات الشاشة الرئيسية، البلاطة السريعة، إشعار الرد، المساعد الصوتي** (أندرويد أصلي).
- الأصوات/TTS السحابي (تبقى قراءة الرد عبر expo-speech).
- ملف `server/` ومجلد `android-*` القديمان لم يعودا لازمين.

### Development Build (لتسجيل Google والإشعارات الكاملة)
```bash
npx expo prebuild
npx expo run:android      # أو: eas build -p android --profile development
```
مفتاح توقيع التطبيق (SHA-1) يجب أن يطابق ما سُجّل لمعرّف Google للحزمة `com.krazos.quarkai`، وإلا فسيفشل الدخول.
في Expo Go تعمل كل الميزات عدا تسجيل Google (تظهر رسالة توضيحية) وقد تُقيَّد الإشعارات.

> لم أستطع تشغيل التطبيق هنا (لا وصول لـ npm)، فالاختبارات (35) تغطي المنطق الصرف فقط. إن ظهر خطأ عند التشغيل أرسل لي نصه وأصلحه.

## ملاحظات

- **الاتجاه RTL**: تفرضه كل شاشة بـ `direction: 'rtl'` فلا يعتمد على إعادة تشغيل التطبيق.
- **الخادم المحلي (Ollama/LM Studio)**: استخدم عنوان جهازك على الشبكة (مثل `http://192.168.1.5:11434`) لا `localhost`، وشغّل Ollama مع `OLLAMA_HOST=0.0.0.0`.
- **المفاتيح** تُخزَّن في AsyncStorage على الجهاز (كما في النسخة القديمة) وتدخل في النسخة الاحتياطية — لا تشاركها.
