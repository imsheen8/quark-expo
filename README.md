# QUARK AI — نسخة Expo (React Native)

إعادة بناء كاملة من الصفر لتطبيق QUARK AI باستخدام **Expo SDK 54 + expo-router + TypeScript**، بدل نسخة الويب/Capacitor القديمة. الواجهة عربية RTL بالكامل، والتطبيق يتصل مباشرة بالمزوّد من الهاتف (لا حاجة لبوابة بايثون ولا لإعداد CORS).

## التشغيل

```bash
npm install
npx expo install --fix      # يوائم أرقام إصدارات الحزم مع SDK المثبّت عندك
npx expo start              # امسح الرمز بتطبيق Expo Go (أندرويد/آيفون)
npm test                    # اختبارات المنطق (30 اختبارًا)
```

> بُني المشروع في بيئة بلا وصول لمستودع npm، فلم يُشغَّل على جهاز/محاكي ولم يُجرَ فحص `tsc` كامل. اختُبر المنطق الصرف بالاختبارات وفُحصت صياغة كل الملفات. أول تشغيل قد يكشف تفاصيل صغيرة في الأنواع أو أرقام الإصدارات — `npm run typecheck` يدلّك عليها.

### بناء APK / تثبيت

```bash
npx eas build -p android --profile preview     # APK عبر EAS
# أو محليًا:
npx expo prebuild && cd android && ./gradlew assembleRelease
```

## ما لم يُنقل (يحتاج وحدات أصلية أو خادمًا) 

- **النماذج على الجهاز (llama.cpp / wllama)** والتنزيل في الخلفية — تحتاج وحدة أصلية مخصصة (مثل `llama.rn`) وبناء Development Build.
- **ودجتات الشاشة الرئيسية، البلاطة السريعة، إشعار الرد، المساعد الصوتي** (أندرويد أصلي).
- الأصوات/TTS السحابي (تبقى قراءة الرد عبر expo-speech).
- ملف `server/` ومجلد `android-*` القديمان لم يعودا لازمين.

### Development Build (لتسجيل Google والإشعارات الكاملة)
```bash
npx expo prebuild
npx expo run:android      # أو: eas build -p android --profile development
```
مفتاح توقيع التطبيق (SHA-1) يجب أن يطابق ما سُجّل لمعرّف Google للحزمة `com.krazos.quarkai`، وإلا فسيفشل الدخول.
في Expo Go تعمل كل الميزات عدا تسجيل Google (تظهر رسالة توضيحية) وقد تُقيَّد الإشعارات.

> لم أستطع تشغيل التطبيق هنا (لا وصول لـ npm)، فالاختبارات (35) تغطي المنطق الصرف فقط. إن ظهر خطأ عند التشغيل أرسل لي نصه وأصلحه.

## النماذج على الجهاز (llama.cpp)

الإعدادات ← «نماذج على الجهاز» (أو من صفحة النماذج). تنزّل ملفات GGUF من Hugging Face (كتالوج مقترح + بحث + لصق owner/repo أو رابط) وتختار صيغة التكميم الأنسب لذاكرة جهازك، ثم تظهر تحت نقطة اتصال «على الجهاز» وتُستخدم في الدردشة كأي نموذج آخر، دون إنترنت.

- **تحتاج Development Build** لأن المحرك (`llama.rn`) وحدة أصلية لا توجد في Expo Go:
  ```bash
  npm_config_legacy_peer_deps=true npm install
  npx expo prebuild
  npx expo run:android        # أو: eas build -p android --profile development
  ```
  في Expo Go تعمل شاشة التنزيل والإدارة، أما التشغيل فيعرض رسالة توضح ذلك.
- النماذج النصية فقط حاليًا (بلا رؤية/صور)، والتشغيل على المعالج (CPU). التقديرات في الشاشة تقريبية.
- أول رد بعد اختيار نموذج أبطأ (يُحمَّل في الذاكرة). النماذج الكبيرة على أجهزة 4–6 GB ذاكرة قد تتعطل: التزم بتصنيف «مناسب/ممتاز».
- التنزيل يحتاج بقاء التطبيق مفتوحًا، وتُحذف الأجزاء غير المكتملة عند الإلغاء.

## بناء APK عبر GitHub Actions

1. أنشئ مستودعًا على GitHub وارفع محتويات هذا المجلد إليه (الملف `.github/workflows/build-apk.yml` موجود مسبقًا).
2. من تبويب **Actions ← Build Android APK ← Run workflow**. (أو ادفع وسمًا مثل `v1.0.0` ليُرفع الـ APK تلقائيًا إلى **Releases**.)
3. بعد ~15–25 دقيقة نزّل `QUARK-AI-apk` من أسفل صفحة التشغيل (Artifacts)، فكّ الضغط، ثم ثبّت `QUARK-AI.apk` (فعّل «التثبيت من مصادر غير معروفة»).

ملاحظات: يُبنى لمعمارية arm64 (أغلب الهواتف). بلا أسرار توقيع يُوقَّع بمفتاح debug المؤقت (صالح للتثبيت الشخصي فقط). تشغيل النماذج المحلية يعمل في هذا الـ APK لأنه يتضمن `llama.rn`.

### توقيع ثابت (لتحديث التطبيق فوق النسخة المثبتة)
بدون مفتاح ثابت يتغيّر توقيع كل بناء فيرفض أندرويد التحديث ويطلب حذف النسخة القديمة. افعل هذا **مرة واحدة**:
1. أنشئ المفتاح: `bash scripts/make-keystore.sh` (في Termux: `pkg install openjdk-17` أولًا). يُنشئ `quark-release.jks` ويطبع كلمة السر، ويكتب `quark-release.jks.b64`.
2. في GitHub: **Settings ← Secrets and variables ← Actions ← New repository secret**، أضف أربعة أسرار بهذه الأسماء بالضبط:
   `ANDROID_KEYSTORE_BASE64` (محتوى ملف `.b64` كاملًا) · `ANDROID_KEYSTORE_PASSWORD` · `ANDROID_KEY_ALIAS` · `ANDROID_KEY_PASSWORD`
3. شغّل البناء. في آخره تظهر بصمة الشهادة، ويُكتب «موقّع بالمفتاح الثابت». إن كانت الأسرار ناقصة يفشل البناء برسالة واضحة؛ وإن غابت كلها يُحذّر ويُوقَّع بـ debug.
4. احتفظ بنسخة من `quark-release.jks` وكلمة السر **خارج المستودع** — إن ضاعا فلن تُحدَّث النسخ المثبتة أبدًا. وأول مرة بعد التحويل احذف النسخة المثبتة القديمة (الموقّعة بـ debug) ثم ثبّت الجديدة؛ بعدها تتحدّث فوق بعضها.
الآلية: `plugins/withQuarkSigning.js` يضيف إلى `build.gradle` عند prebuild توقيعًا يقرأ متغيرات البيئة التي تجهّزها خطوة «Prepare release signing».

## المهارات

المهارة حزمة تعليمات بصيغة SKILL.md (اسم + وصف + «متى تُستخدم» + خطوات + وسوم). يطابق التطبيق طلبك مع المهارات المنشورة ويحقن الأنسب (حتى العدد الذي تحدده) في سياق النموذج، وتظهر أسفل الرد شارة «✦ مهارات: …». اكتب `/` في خانة الرسالة لتثبيت مهارة للرسالة التالية. من **الإعدادات ← المهارات**: إنشاء/تعديل، تجربة مهارة على طلب، استيراد (رابط GitHub، لصق، ملف .md/.json)، تصدير، استخراج مهارة من محادثة (تُحفظ كمسودة)، وضبط الحساسية والعدد. تأتي معها 5 مهارات مدمجة.

## الصوت

**الإعدادات ← الصوت** بثلاثة تبويبات:
- **المفاتيح:** أضف مفتاح مزوّد مرة واحدة (OpenAI · Groq · ElevenLabs · Deepgram · Gemini · مخصص متوافق مع OpenAI) مع زر اختبار.
- **القراءة:** اختر المزوّد والنموذج والصوت والسرعة. زر 🔊 تحت كل رد يقرأه بهذا الصوت، وبلا مفتاح قراءة يُستخدم صوت الجهاز.
- **التعرّف:** اختر المزوّد والنموذج واللغة، مع اختبار بتسجيل 4 ثوانٍ. بعدها يظهر زر 🎤 في خانة الرسالة: اضغط لبدء التسجيل واضغط ثانية ليتحوّل كلامك إلى نص.

**الأصوات** (من الإعدادات ← الصوت ← استوديو الأصوات): تجربة أي صوت بنص تجريبي دون تغيير المختار، قياس زمن التوليد، مفضلة، بحث، أصوات مخصصة (معرّف + نموذج خاص)، وزر «استخدام». يعمل في Expo Go (`expo-audio`)، وصلاحية الميكروفون تُطلب عند أول تسجيل.

## النماذج التلقائية

**الإعدادات ← النماذج التلقائية:** نموذج مستقل لكل مهمة: المحادثات الجديدة (يُطبَّق عند «محادثة جديدة»)، المهام الخلفية (العنوان التلقائي واستخراج المهارات)، الرؤية (عند إرسال صورة لنموذج لا يدعمها)، والبحث العميق. للخلفية والرؤية حتى 4 بدائل احتياطية تُجرَّب بالترتيب إن فشل النموذج قبل أن يصل أي رد، وأي نموذج غير صالح (نقطة معطّلة أو بلا مفتاح) يُتخطّى.

## ملاحظات

- **الاتجاه RTL**: تفرضه كل شاشة بـ `direction: 'rtl'` فلا يعتمد على إعادة تشغيل التطبيق.
- **الخادم المحلي (Ollama/LM Studio)**: استخدم عنوان جهازك على الشبكة (مثل `http://192.168.1.5:11434`) لا `localhost`، وشغّل Ollama مع `OLLAMA_HOST=0.0.0.0`.
- **المفاتيح** تُخزَّن في AsyncStorage على الجهاز (كما في النسخة القديمة) وتدخل في النسخة الاحتياطية — لا تشاركها.

## صفحة النماذج المتقدمة
من «النماذج» ← تبويب **النماذج** (وبجانبه «نقاط الاتصال» كما كان):
- بطاقة لكل نموذج: اسم مستعار، ملاحظة، لون، مفضلة، عدد الاستخدام، نتيجة آخر اختبار، وشارات القدرات (تقدير بحسب الاسم).
- اضغط البطاقة لورقة **التفاصيل**: إحصاءات وسجل الاختبارات، تعديل الاسم والملاحظة واللون، المعاملات الفعلية.
- **ساحة التجربة**: اختر نموذجًا واكتب سؤالًا لتقيس زمن أول رمز والزمن الكلي وسرعة التوليد (رمز/ث).
- **مقارنة الأداء**: حدّد حتى 8 نماذج (ضغطة مطوّلة أو زر التحديد المتعدد) ثم «مقارنة أداء»؛ يعمل 3 نماذج بالتوازي ويُبرز الأفضل.
- **فلاتر**: تبويبات (الكل/المفضلة/المفعّلة/المستخدمة)، نقطة الاتصال، القدرة، الحالة، العائلة، والترتيب.
- **نظرة عامة**: صحة الاتصال، الأسرع، الأكثر استخدامًا، العائلات، **كشف المكررات** مع «تنظيف المكررات»، وتصدير/استيراد (بدون مفاتيح API).

- تعديل رسالتك يحفظ النسخة القديمة بردودها؛ يظهر تحتها `‹ ن/م ›` للتنقل بين النسخ.

## أندرويد الأصلي: ودجتات واختصارات
تُولَّد عند `expo prebuild` (أو بناء GitHub Actions) بإضافة `plugins/withQuarkNative.js`، ولا تعمل في Expo Go (تحتاج APK/Dev build):
- **ودجت 4×2**: شريط «اكتب رسالة» + كاميرا + معرض + إملاء + محادثة جديدة. **ودجت 2×2**: محادثة + إملاء + كاميرا. الألوان تتبع وضع النظام. تُضاف بالضغط المطوّل على الشاشة الرئيسية ← الأدوات.
- **اختصارات الأيقونة** (ضغط مطوّل على أيقونة التطبيق): محادثة جديدة، إملاء صوتي، الإعدادات، الإحصائيات.
- **بلاطة الإعدادات السريعة**: من لوحة الإشعارات ← القلم ← اسحب «QUARK AI».
- الآلية: كل زر يفتح رابطًا `quarkai://a/<new|chat|camera|photo|mic|settings|stats>` يعالجه `app/a/[action].tsx`، وتُؤجَّل الكاميرا/الإملاء حتى يُفتح القفل.
- غير مُنقول من القديم: ودجت الإحصائيات (يحتاج جسرًا أصليًا لإرسال الأرقام)، وزر «إضافة الودجت» من الإعدادات.

## معاينة HTML/SVG المباشرة
كتل الكود `html`/`svg` (أو كتلة بلا لغة تبدو كذلك) يظهر في رأسها زر **معاينة** و**ملء الشاشة** بعد اكتمال الرد. تُعرض في WebView معزول: بلا شبكة إلا مكتبات CDN المعروفة (سياسة CSP)، بلا تخزين ولا ملفات، ولا يُسمح بالانتقال لأي موقع.

## حذف الحساب والاشتراك
أُزيل تسجيل الدخول بـ Google وصفحة الاشتراك والأكواد والمزامنة السحابية ونقطة «QUARK» المُدارة. التطبيق يعمل محليًا بالكامل بمفاتيحك أنت. بقي «الملف الشخصي» (الاسم والتفضيلات) محليًا على الجهاز، وتُنظَّف تلقائيًا بقايا الحساب القديم من الإعدادات المحفوظة.

## سجل الأخطاء
«الإعدادات ← سجل الأخطاء»: يعرض أخطاء الاتصال (`net`) والتوليد (`gen`) والعنوان والبدائل الاحتياطية (`fallback`) واختبار النماذج (`test`) والبحث (`web`) والوكيل والبحث العميق والمهام والصوت وأخطاء JavaScript غير المعالجة (`js`). كل سطر بصيغة `Σ` (منذ أول سجل) و`Δ` (منذ السابق). تصفية بـ regex، ترتيب أحدث/أقدم، «الأخطاء فقط»، مشاركة كملف نصي، ونسخ سطر بالضغط المطوّل. تُخفى المفاتيح والتوكنات تلقائيًا قبل الحفظ، ويُحفظ آخر 400 سطر على الجهاز.
